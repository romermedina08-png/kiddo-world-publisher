Privacy Policy

Kiddo World Publisher

The short version: this tool holds one access token on one computer, collects nothing about anybody, and sends nothing to anyone.

01Scope

This policy covers Kiddo World Publisher, an internal tool that uploads videos produced by the operator to the drafts of the operator's own TikTok account. The application has no public users, no website, no sign-up, and no user accounts of its own.

02What the application handles

DataWhyWhere it is kept
TikTok access and refresh tokens To upload a video to the operator's own drafts without asking for a password A file on the operator's computer
Video files and their captions They are the thing being uploaded The operator's computer, then TikTok

That is the complete list. The tokens are issued by TikTok when the operator approves the application on TikTok's own authorization screen. The application never sees or stores a TikTok password.

03What it does not collect

  • No personal information about viewers, followers, or any other TikTok user.
  • No analytics, tracking pixels, cookies, or advertising identifiers.
  • No location data, contacts, or device identifiers.
  • No data about anyone other than the operator's own account.

04Sharing

Nothing is shared, sold, or transferred to anyone. There are no third parties, no processors, and no advertising partners. The only service the application contacts is TikTok itself, to perform the upload the operator asked for.

05Retention and deletion

The stored token stays on the operator's computer for as long as the tool is in use. Deleting the token file removes it immediately. Uninstalling the tool, or revoking access as described below, ends all access.

06How to revoke access

In the TikTok app: Profile → Settings and privacy → Security and permissions → Manage app permissions, then remove Kiddo World Publisher. Access stops at once, and any stored token becomes useless.

07Children

The channel makes videos for young children, but this application is not for children and is not used by them. It is a publishing tool run by one adult on one computer. It does not knowingly collect information from anyone, and it collects nothing at all from children.

08Security

The token file is stored on the operator's own computer and is not committed to any repository or shared drive. All communication with TikTok uses HTTPS.

09Changes

If this policy changes, the updated version appears on this page with a new effective date.
